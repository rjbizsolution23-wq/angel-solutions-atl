## 🔌 PHASE 3: INTEGRATION KEYS (ENVIRONMENT PARAMS)

Go to **Base44 Settings → Environment Variables** and configure:

* `OPENROUTER_API_KEY`: For game script compilations (DeepSeek V3).
* `TOGETHER_API_KEY`: For 16-bit pixel art sprite generators (FLUX.1).

* `CLOUDFLARE_R2_BUCKET_URL`: To store game files on Cloudflare.

## 🕹️ PHASE 5: HOW TO RUN EMULATOR ENGINE

Make sure your Game Detail page references the initialized EmulatorJS engine:
```html
<script src="https://cdn.emulatorjs.org/stable/data/loader.js"></script>
```
The game details page scripts segment will automatically invoke `initEmulator(romUrl, platform)` where `romUrl` is directed to our edge-caching mirror proxy: `/api/games/proxy?id={gameId}&file={file}`.

---

## 🆘 TROUBLESHOOTING

* **ROM Failing to load**: Verify that the ROM's filename maps correctly to its emulator platform core (e.g. `.nes` for `nes`, `.smc` for `snes`).
* **AI Game Build Hitting Timeout**: Increase the fetch response duration threshold in Base44 integrations to allow DeepSeek V3 to finish generating larger Phaser script blocks (~15s).
* **CSS Fonts Failing**: Clear your local browser cache to re-pull the Google Web Font style stylesheets.
