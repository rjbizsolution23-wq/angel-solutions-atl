## 🆘 TROUBLESHOOTING

### Problem: "Pages aren't showing up"
**Solution**: Make sure you pasted prompts into Builder Chat one at a time and waited for each to complete. Check the Pages list in Base44 Builder.

### Problem: "Styling doesn't look retro"
**Solution**: Clear browser cache (Ctrl+Shift+R). Verify CSS is saved in Settings → Custom CSS. Check if fonts are loading (Network tab).

### Problem: "Emulator not loading"
**Solution**: Verify EmulatorJS script is in Custom Head Scripts. Check ROM file URL is accessible. Ensure platform maps to correct core in code.

### Problem: "AI generation failing"
**Solution**: Verify API keys in Environment Variables. Check rate limits. Look at ai_generation_history table for error messages.

### Problem: "Can't upload ROMs"
**Solution**: Verify Cloudflare R2 credentials. Check bucket names match code. Ensure CORS policy is set correctly.
