### Unity Game Modding

#### Primary Tools
1. **BepInEx** - https://github.com/bepinex/bepinex
   - ⭐ ESSENTIAL Unity mod framework
   - Plugin system
   - Harmony patching
   - IL2CPP support
   - **Install:** Copy to game root, run once
   - **Version:** Latest stable from GitHub

2. **MelonLoader** - https://melonwiki.xyz/
   - Alternative to BepInEx
   - IL2CPP focus
   - Mod loader framework

3. **Unity Mod Manager** - https://www.nexusmods.com/site/mods/21
   - GUI-based mod manager
   - One-click installation
   - Update checking

#### Unity Asset Extraction
1. **AssetRipper** - https://github.com/assetripper/assetripper
   - ⭐ BEST Unity asset ripper
   - Extract models, textures, code
   - Convert to native formats
   - GUI application
   - **Supports:** Unity 3.5 - Unity 6000.5.X
   - **Features:**
     - Extract all asset types
     - Decompile C# scripts
     - Export to Blender/Unity formats
     - Batch processing

2. **UABE (Unity Asset Bundle Extractor)** - https://github.com/SeriousCache/UABE
   - Edit Unity asset files
   - Texture replacement
   - Bundle extraction

3. **DevX UnityPack** - https://github.com/HearthSim/UnityPack
   - Python library
   - Extract Unity assets
   - Command-line tool

#### Unity Code Tools
1. **dnSpy** - https://github.com/dnSpyEx/dnSpy
   - ⭐ C# decompiler and editor
   - Debug .NET applications
   - Edit code in-place
   - **Essential for Unity modding**

2. **ILSpy** - https://github.com/icsharpcode/ILSpy
   - .NET decompiler
   - Open source
   - Cross-platform

3. **JustDecompile** (Legacy)
   - Telerik decompiler
   - Historical tool

#### Unity Modding Workflow
```
1. Check if game uses Unity (UnityPlayer.dll present)
2. Install BepInEx to game folder
3. Run game once to generate folders
4. Create plugin in BepInEx/plugins/
5. Use Harmony to patch game methods
6. Test and iterate
```

## 🎯 QUICK START WORKFLOWS

### "I want to make a ROM hack"
```
1. Choose platform (SNES, Genesis, NES, etc.)
2. Download emulator with debugging (FCEUX, BGB, etc.)
3. Get hex editor (HxD)
4. Find ROM hacking tools for your platform
5. Start with simple edits (text, values)
6. Learn platform-specific assembly
7. Progress to graphics, music, levels
```
