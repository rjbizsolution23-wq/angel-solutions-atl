## 🕹️ RETRO DEVELOPMENT PATH

### For SNES Games

**Step 1: Install Development Kit**
- Download: [PVSnesLib](https://github.com/alekmaul/pvsneslib)
- Alternative: [SNES-IDE](https://github.com/BrunoRNS/SNES-IDE) (easier GUI)

**Step 2: Learn C Basics**
- Free Resource: [Learn C](https://www.learn-c.org/)
- Time: 2-3 weeks

**Step 3: Follow Tutorial**
- Start: [SNES Development Part 1](https://blog.wesleyac.com/posts/snes-dev-1-getting-started)
- Watch: [SNES Assembly Adventure](https://georgjz.github.io/snesaa01/)

**Step 4: First Project**
- Build: "Hello World" ROM
- Test: In SNES emulator (SNES9x or bsnes)

**Expected Timeline:** 1-2 months to first playable game

---

### For Sega Genesis/Mega Drive Games

**Step 1: Install SGDK**
- Download: [SGDK](https://github.com/Stephane-D/sgdk)
- Setup: Includes C compiler, sprite/tile tools

**Step 2: Learn C Basics**
- Same as SNES path above

**Step 3: Follow Tutorial**
- Watch: [Pigsy's Genesis Tutorial Series](https://www.youtube.com/@PigsysRetroGameDevTutorials)
- Read: [Genesis Programming Guide](https://huguesjohnson.com/programming/genesis/palettes/)

**Step 4: First Project**
- Build: Simple sprite demo
- Test: In Genesis emulator (Kega Fusion or Gens)

**Expected Timeline:** 1-2 months to first playable game

## 🎮 2D MODERN PATH

### Best Engine Options (Pick One)

#### Option A: **Godot** (Recommended for Beginners)
**Why:** Free, open-source, easy to learn, great 2D tools

**Setup (10 minutes):**
1. Download: [Godot Engine](https://godotengine.org/)
2. Install (portable, no installation needed)
3. Launch and create new project

**Learning:**
- Official Tutorial: [Your First 2D Game](https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html)
- YouTube: [GDQuest Tutorials](https://www.youtube.com/c/gdquest)
- Time: 1 week to basics, 1 month to confidence

**First Project:** Dodge the Creeps (official tutorial)
**Timeline:** 2-3 months to publishable game

---

#### Option B: **GameMaker**
**Why:** Industry-proven (Undertale, Hotline Miami), drag-and-drop friendly

**Setup:**
1. Download: [GameMaker](https://gamemaker.io/)
2. Free trial, then $5/month

**Learning:**
- Official: [GameMaker Tutorials](https://gamemaker.io/en/tutorials)
- YouTube: [Shaun Spalding](https://www.youtube.com/c/ShaunSpalding)

**Timeline:** 1-2 months to first game

---

#### Option C: **Phaser** (Web Games)
**Why:** JavaScript, browser-based, instantly playable

**Setup (5 minutes):**
1. Create `index.html` file
2. Include Phaser library
3. Write game code

**Learning:**
- Official: [Phaser 3 Tutorial](https://phaser.io/tutorials/making-your-first-phaser-3-game)
- Time: 1-2 weeks if you know JavaScript

**First Project:** Platform game tutorial
**Timeline:** 2-4 weeks to first web game

## 🌟 3D MODERN PATH

### Best Engine Options (Pick One)

#### Option A: **Godot 4** (Recommended for Beginners)
**Why:** Free, modern 3D features, easier than Unity/Unreal

**Setup (10 minutes):**
1. Download: [Godot 4](https://godotengine.org/)
2. Install
3. Create 3D project

**Learning:**
- Tutorial: [Your First 3D Game](https://docs.godotengine.org/en/stable/getting_started/first_3d_game/index.html)
- YouTube: [Brackeys Godot Tutorials](https://www.youtube.com/playlist?list=PLhqJJNjsQ7KH_z21S_XeXD3Ht3WnSqW97)

**Timeline:** 3-6 months to publishable 3D game

---

#### Option B: **Unity**
**Why:** Industry standard, huge asset store, job market

**Setup (30 minutes):**
1. Download: [Unity Hub](https://unity.com/)
2. Install Unity Editor (LTS version)
3. Create 3D project

**Learning:**
- Official: [Unity Learn](https://learn.unity.com/)
- YouTube: [Brackeys](https://www.youtube.com/user/Brackeys) (archived but excellent)
- Course: [Complete C# Unity Game Developer 3D](https://www.gamedev.tv/)

**Timeline:** 6-12 months to publishable game

---

#### Option C: **Unreal Engine**
**Why:** AAA graphics, Blueprint visual scripting, free until $1M revenue

**Setup (1 hour):**
1. Download: [Epic Games Launcher](https://www.unrealengine.com/)
2. Install Unreal Engine 5
3. Create Third Person template

**Learning:**
- Official: [Unreal Learning](https://www.unrealengine.com/en-US/onlinelearning-courses)
- YouTube: [Unreal Sensei](https://www.youtube.com/c/unrealsensei)

**Timeline:** 6-12 months to publishable game

## 🌐 WEB GAMES PATH

### Option A: **Phaser 3** (Recommended)
**Best For:** 2D games, HTML5, mobile web

**5-Minute Setup:**
```html
<!DOCTYPE html>
<html>
<head>
    <script src="https://cdn.jsdelivr.net/npm/phaser@3/dist/phaser.min.js"></script>
</head>
<body>
    <script src="game.js"></script>
</body>
</html>
```

**Learn:** [Making Your First Phaser 3 Game](https://phaser.io/tutorials/making-your-first-phaser-3-game)

---

### Option B: **Three.js** (3D Web)
**Best For:** 3D browser experiences, WebGL

**Setup:**
```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
```

**Learn:** [Three.js Journey](https://threejs-journey.com/)

---

### Option C: **Babylon.js** (Advanced 3D)
**Best For:** Serious 3D web games, physics

**Learn:** [Babylon.js Documentation](https://doc.babylonjs.com/)

## 🎯 YOUR FIRST GAME (CRITICAL ADVICE)

### ❌ DON'T Make:
- Your dream MMO
- Open world RPG
- Battle royale
- Anything requiring years of work

### ✅ DO Make:
- **Pong clone** - 1 weekend
- **Flappy Bird clone** - 1 week
- **Match-3 puzzle** - 2 weeks
- **Simple platformer** - 1 month

### Why Small First?
1. **Learn the full process** - Design → Build → Test → Publish
2. **Stay motivated** - Finish projects, build confidence
3. **Portfolio** - Multiple small games > One unfinished big game

## 🎓 FREE LEARNING PATHS

### Absolute Beginner (No Coding)
1. **Week 1-2:** Scratch (visual programming) - [scratch.mit.edu](https://scratch.mit.edu/)
2. **Week 3-4:** Construct 3 (drag-and-drop) - [construct.net](https://www.construct.net/)
3. **Month 2:** GameMaker (minimal coding)
4. **Month 3+:** Godot (proper game engine)

### Some Coding Experience
1. **Day 1:** Choose engine (Godot recommended)
2. **Week 1:** Official tutorials
3. **Week 2-4:** Clone existing games
4. **Month 2:** Game jam participation
5. **Month 3+:** Original game project

### Strong Programming Background
1. **Day 1:** Download Unity or Unreal
2. **Week 1:** Complete official tutorial series
3. **Week 2:** Game jam (48 hours)
4. **Month 1-3:** Ambitious first project
5. **Month 4+:** Specialize (multiplayer, VFX, etc.)

## 💡 PRO TIPS

### 1. **Join Communities EARLY**
- Reddit: r/gamedev, r/godot, r/unity3d
- Discord: Godot, Unity, Gamedev.tv
- Forums: TIGSource, GameDev.net

### 2. **Participate in Game Jams**
- Ludum Dare (3 times/year)
- Global Game Jam (January)

### 3. **Document Your Journey**

### 4. **Focus on Finishing**
- Scope small
- Set deadlines
- Ship > perfect

### 5. **Learn From Others**
- Play indie games critically
- Watch postmortems (GDC Vault)
- Study successful games in your genre

## 🚨 COMMON BEGINNER MISTAKES

### ❌ Starting Too Big
**Solution:** Make Pong before making Skyrim

### ❌ Engine Hopping
**Solution:** Stick with one engine for 6 months minimum

### ❌ Tutorial Hell
**Solution:** After 3 tutorials, start your own project

### ❌ Working Alone (Always)
**Solution:** Join game jams, get feedback, collaborate

### ❌ Ignoring Art/Audio
**Solution:** Use free assets, iterate later

### ❌ Not Publishing
**Solution:** Publish on itch.io, even if "not ready"
