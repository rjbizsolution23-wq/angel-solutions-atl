# QUALITY STANDARD

Do not stop after summarizing.

Do not skip sections.

Do not simplify complex topics unnecessarily.

Your objective is to produce a resource that could replace the original documentation for learning and implementation while remaining faithful to the source material.

Continue until the documentation has been comprehensively analyzed and transformed into a complete expert-level reference manual.

If multiple documentation sources are supplied, merge them into one unified knowledge base and resolve overlaps by prioritizing the newest, most authoritative documentation while explicitly noting any conflicts.

This template is documentation-agnostic—you can drop in **one URL, dozens of URLs, PDFs, GitHub repos, or an entire documentation site**, and it instructs the agent to build a comprehensive, expert-level reference. If you want to push this to the highest level, the next step is turning it into a **Documentation Intelligence System** with recursive crawling, semantic indexing, cross-document linking, version comparison, gap analysis, implementation planning, and an AI-queryable knowledge base.
