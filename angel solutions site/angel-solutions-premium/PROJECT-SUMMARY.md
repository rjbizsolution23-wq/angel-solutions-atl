## 🛠️ Technical Setup Instructions

### 1. Initial Setup
```bash
cd angel-solutions-premium
npm install
```

### 2. Environment Configuration
Create `.env.local`:
```env
NEXT_PUBLIC_SITE_URL=https://angelsolutionsatl.com
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
SENDGRID_API_KEY=your_key_here
```

### 3. Development
```bash
npm run dev
# Visit http://localhost:3000
```

### 4. Build & Test
```bash
npm run build
npm start
```

### 5. Deploy to Vercel
```bash
npm i -g vercel
vercel login
vercel --prod
```

## 🎨 Customization Guide

### Change Colors
Edit `tailwind.config.ts`:
```typescript
colors: {
  brand: {
    gold: {
      500: '#d4a05a', // Change this
    }
  }
}
```

### Update Content
Edit `lib/constants.ts`:
```typescript
export const SITE_CONFIG = {
  name: 'Your Business Name',
  email: 'your@email.com',
  // ... more settings
}
```

### Add New Pages
1. Create `/app/your-page/page.tsx`
2. Add to navigation in `lib/constants.ts`
3. Update sitemap
